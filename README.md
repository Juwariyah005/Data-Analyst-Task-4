# 🍽️ Zomato Restaurant Analysis Dashboard

## 📌 Project Overview

This project focuses on analyzing Zomato restaurant data and creating an interactive dashboard using **Microsoft Power BI**.

The dashboard provides insights into restaurant ratings, customer engagement, restaurant categories, online ordering, table booking availability, and approximate dining costs.

The main objective is to transform raw restaurant data into meaningful visualizations that help stakeholders understand restaurant performance and customer preferences.

## 🎯 Project Objectives

- Analyze restaurant ratings and customer votes.
- Understand the distribution of different restaurant types.
- Explore online ordering and table booking availability.
- Compare restaurant ratings with approximate costs.
- Build an interactive and visually appealing Power BI dashboard.
- Present important business insights using KPI cards and charts.

## 🛠️ Tools & Technologies

- **Microsoft Power BI** – Dashboard development and visualization.
- **Power Query** – Data cleaning and transformation.
- **DAX (Data Analysis Expressions)** – KPI calculations and measures.
- **CSV Dataset** – Restaurant data source.

## 📂 Dataset Information

The dataset contains restaurant-related information with the following columns:

| Column | Description |
|---|---|
| name | Restaurant name |
| online_order | Online ordering availability |
| book_table | Table booking availability |
| rate | Restaurant rating |
| votes | Number of customer votes |
| approx_cost(for two people) | Estimated cost for two people |
| listed_in(type) | Restaurant category |

## 📊 Key Performance Indicators (KPIs)

The dashboard displays the following key metrics:

| KPI | Dashboard Value |
|---|---:|
| Total Restaurants | 148 |
| Total Votes | 39K |
| Average Rating | 3.63 / 5 |
| Average Cost for Two | ₹418.24 |
| Table Booking Restaurants | 8 |

*Values are based on the dashboard at the time of capture.*

## 📈 Dashboard Visualizations

The Power BI dashboard includes:

1. **Restaurant Distribution:** Shows the number of restaurants across different restaurant categories.
2. **Online Order Analysis:** Explores online ordering across restaurant listings.
3. **Average Rating Analysis:** Compares ratings of different restaurants.
4. **Cost Analysis:** Examines approximate dining costs.
5. **Cost vs Rating Scatter Plot:** Visualizes the relationship between restaurant cost and ratings.
6. **KPI Cards:** Summarize important restaurant metrics.

## 🔍 Key Insights

- Dining represents the largest restaurant category, with 110 listings (74.32%).
- Cafes account for 23 listings (15.54%).
- The overall average restaurant rating is 3.63 out of 5.
- The average estimated cost for two people is ₹418.24.
- The dataset contains approximately 39K customer votes.
- Onesta appears among the highest-rated restaurants in the displayed rating chart, with a rating of 4.6.
